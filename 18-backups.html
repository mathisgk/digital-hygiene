Briefing 18 | Threat class: ransomware and data loss

Backups

Mission objective. Have a recovery plan before you need one.

Field report

  • 3-2-1: three copies, on two kinds of media, one offsite.
  • An external drive disconnected from the network and stored unplugged is ransomware-proof, because ransomware cannot encrypt what it cannot reach. Pair it with a cloud backup.
  • Sync is not backup. If a file is deleted or encrypted, sync copies the damage.
  • Test a restore. An untested backup is a rumor.
  • Backups, not antivirus, are the real answer to ransomware.

Myth versus reality

Myth“It is in the cloud, so it is backed up.”
RealityOnly if it survives a deleted account, a hijack, and a sync mistake.
