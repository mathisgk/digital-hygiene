Briefing 07 | Threat class: lookup logging

DNS, the phonebook of the internet

Mission objective. See that every site name you visit is a lookup someone can log.

Field report

  • DNS turns google.com into an IP address. By default your ISP handles those lookups and sees every site you visit. Even on a VPN, a misconfigured setup can leak lookups outside the tunnel.
  • Options: Proton's NetShield (paid, DNS-level tracker and malware blocking), NextDNS (granular control, free tier, can conflict with a VPN's own DNS if both run), Quad9 and Cloudflare 1.1.1.1 (fast, privacy-oriented public resolvers).
  • Encrypted DNS (DoH or DoT) hides lookups from the network in between. Plain DNS is readable by anyone on the path.
  • Rule: one DNS layer at a time. If your VPN filters DNS, use that. If not, set one encrypted resolver on the device or router. A second resolver as a fallback if the VPN drops is optional, and two filtering layers can fight each other.
  • Verify at dnsleaktest.com. Never assume.

Myth versus reality

Myth“If I'm on a VPN, DNS is handled.”
RealityOnly if you tested it.

Field exercise

Wireshark lab: capture DNS on a classroom laptop with default settings and read the site names in plaintext. Switch to encrypted DNS and capture again. The simulator below shows the idea.
